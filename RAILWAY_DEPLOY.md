# Deploying Frappe Education on Railway

This repository is configured to deploy **Frappe Education** (with ERPNext and the Frappe Framework) onto [Railway](https://railway.com).

## Architecture

1. **`frappe-education`** (App Service)
   - Built from root `Dockerfile` using `frappe/erpnext:v16.34.2` base image.
   - Installs `supervisor` to manage Gunicorn, Socket.IO, RQ workers, Scheduler, and Nginx.
   - Installs the forked `education` app and compiles assets.
   - Persistent volume mounted at `/home/frappe/frappe-bench/sites`.
   - Exposes port `8080` (Nginx proxy) with healthcheck on `/api/method/ping`.
2. **`mariadb`** (Database Service)
   - MariaDB 11.8 configured with `utf8mb4` encoding and collation (`utf8mb4_unicode_ci`).
   - Persistent volume mounted at `/var/lib/mysql`.
3. **`redis`** (Queue & Cache Service)
   - Redis Alpine instance with persistent volume at `/var/lib/redis`.

## Environment Variables

| Variable | Description | Example |
|---|---|---|
| `ADMIN_PASSWORD` | Administrator account password | `<auto-generated>` |
| `DB_HOST` | Private MariaDB hostname | `${{mariadb.RAILWAY_PRIVATE_DOMAIN}}` |
| `DB_PORT` | MariaDB port | `3306` |
| `DB_ROOT_PASSWORD` | MariaDB root password | `${{mariadb.MARIADB_ROOT_PASSWORD}}` |
| `REDIS_URL` | Redis URL | `redis://${{redis.RAILWAY_PRIVATE_DOMAIN}}:6379` |
| `SITE_NAME` | Site name header | `frontend` |
| `PORT` | Web listener port | `8080` |
